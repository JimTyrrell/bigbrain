# BigBrain

Personal, PIN-protected chat over named **Brains** of documents (transcripts, PDFs, notes),
running entirely on Cloudflare: Workers, Workers AI (Llama 4 / GPT-OSS / DeepSeek / Whisper),
D1, Vectorize and KV. Live at https://bigbrain.designaticlabs.com.
